FridgeLight is a subscription app that alerts homeowners the instant their refrigerator light turns off — a light nobody can ever see while the door is closed — pitched with total founder confidence, because in a world full of uncertainty, knowing your leftovers are sitting in the dark is peace of mind worth $9.99 a month.

## Run it

```sh
node main.ts
```

Writes `entry.txt` (231 characters, one sentence) to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
